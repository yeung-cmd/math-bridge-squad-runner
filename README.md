# 數學闖關樂園

集合兩大系列、共四款不同玩法與學習焦點的互動數學遊戲，讓老師及學生按練習目標自由揀選：

## 一、2D 心算求值系列
1. **遊戲 01｜《橋樑算術衝鋒》（2D 跑道求值 · 20 題闖關）**
   結合跑道選擇、軍團養成與武器升級，涵蓋 20／50／100 以內加法、基礎數感訓練及乘法表挑戰（2–9），最後與守關首領決戰。
2. **遊戲 02｜《星光燈塔保衛戰》（2D 科幻守塔 · 10 題快玩）**
   限時快答模式，帶領機械人小隊發射能量波擊退逼近怪物、守護護盾並點亮五層星光燈塔。

## 二、3D 路線比較系列
3. **遊戲 03｜《數學大軍：攻城救公主》（3D 城堡攻堅 · 連破三牆）**
   即時比較左右數學門揀選最大兵力，配合限時「答題大炮」機關掃射，先後擊敗外城、中城與內城的多名巨人拯救公主。
4. **遊戲 04｜《數學神炮：雪地三路》（3D 雪地三路 · 三路推線）**
   判斷左中右三條跑道連環運算結果，識破誘餌門並發射藍軍炮陣壓制紅軍（內建老師設定面板與逐回合回顧）。

## 本機運行

需要 Node.js 22 或更新版本：

```bash
npm install
npm run dev
```

## GitHub Pages 發布

將變更推送至 `main` 分支後，`.github/workflows/deploy-pages.yml` 會自動建置並發布至 GitHub Pages。
