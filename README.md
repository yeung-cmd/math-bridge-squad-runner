# 數學橋樑軍團大作戰

結合橋樑跑道選擇、軍團養成與守關首領對決的互動數學遊戲，涵蓋二十以內加法、五十以內加法、一百以內加法及基礎數感題。

## 本機運行

需要 Node.js 22 或更新版本。

```bash
npm install
npm run dev
```

## GitHub Pages 發布

將變更推送至 `main` 分支後，GitHub Actions 會建置並發布網站。首次發布前，請在儲存庫的 **Settings → Pages → Build and deployment** 將來源設為 **GitHub Actions**。

## 操作流程

先在設定頁選擇題目範圍、每題時間、音效及自動衝刺，再按「開始遊戲」。倒數後才開始計時。遊戲中可暫停、繼續、重新開始或返回設定；返回設定後會保留剛才的選項。

跑道與橋面使用獨立動畫值更新，避免每格重繪整個介面；倒數文字每秒最多更新十次。另設衝刺速度線、答對粒子、衝擊波、武器升級提示及首領射擊效果。系統若設定減少動態效果，會自動簡化裝飾動畫。
